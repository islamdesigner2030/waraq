# ورق · Waraq

تطبيق آيفون أصلي (Swift + SwiftUI، مع UIKit وMetal) يحوّل دفترًا ورقيًا فاخرًا إلى مفكرة رقمية بطريقة **Bullet Journal** لرايدر كارول.
يعمل دون اتصال بالكامل: لا حسابات، ولا خوادم، ولا تتبّع، ولا إعلانات، ولا أذونات غير ضرورية.

- **الحد الأدنى:** iOS 26، آيفون فقط، الوضع الرأسي.
- **لا مكتبات خارجية.** خطّان زخرفيان مضمّنان برخصة OFL (Aref Ruqaa وGreat Vibes) لشاشة الترحيب فقط.

---

## مهم: هذا الجهاز ويندوز

تطبيقات iOS لا تُبنى إلا على macOS باستخدام Xcode. لذلك كُتب المشروع كاملًا هنا **دون أن يُجمَّع أو يُشغَّل بعد**.
أول بناء سيكشف أي خطأ ترجمة متبقٍّ (أخطاء صغيرة متوقعة في مشروع بهذا الحجم كُتب دون مترجم)، وإصلاحها سريع.

## طرق البناء

### ١) دون Mac: GitHub Actions (مجاني للمستودعات العامة)
1. أنشئ حسابًا على github.com ومستودعًا جديدًا، وارفع محتوى هذا المجلد كما هو (يمكن السحب والإفلات في صفحة المستودع).
2. يبدأ البناء تلقائيًا من الملف `.github/workflows/ios-build.yml` على جهاز Mac سحابي:
   - يجمّع التطبيق كاملًا للمحاكي (فحص شامل لكل ملفات Swift وMetal).
   - يُخرج ملف `Waraq-unsigned.ipa` غير موقَّع، تجده في صفحة التشغيل تحت **Artifacts**.
   - يشغّل التطبيق في محاكي آيفون ويمرّ على كل الشاشات كمستخدم جديد (بالإنجليزية ثم العربية)، ويلتقط صورة لكل خطوة، ومنها صورة للصفحة وهي في منتصف التقليب بالاتجاهين. تجدها في **Artifacts** باسم `screenshots`.
3. إن فشل البناء أو الاختبار، نزّل `build-logs` (ومعه `screenshots` إن وُجد) وأرسله لي لأصلح الخطأ.
4. لتثبيته على آيفونك يلزم توقيعه بحساب Apple الخاص بك. من ويندوز يمكن ذلك بأدوات مثل Sideloadly أو AltStore (بحساب Apple مجاني يعمل التطبيق ٧ أيام ثم يُعاد توقيعه، أو بحساب مطوّر مدفوع لمدة أطول). هذه أدوات من جهات خارجية، والقرار فيها لك.

### ٢) على Mac فيه Xcode 26
```bash
brew install xcodegen
```
```bash

```
```bash

```
ثم اختر فريقك (Team) في Signing & Capabilities، ووصّل الآيفون، واضغط Run.

### ٣) خدمات Mac سحابية
Codemagic أو Xcode Cloud أو استئجار Mac (مثل MacinCloud): الخطوات نفسها أعلاه.

## رحلة المستخدم

1. **اختيار اللغة** (مرة واحدة): العربية بواجهة من اليمين لليسار، أو الإنجليزية. يُغيَّر لاحقًا من الإعدادات.
2. **الترحيب:** «كل صفحة… بداية جديدة.» بخط زخرفي وظهور هادئ (اضغط للتخطي).
3. **دفاتري:** زر «+» زجاجي في المنتصف عند الفراغ، ومجموعة أغلفة عند وجود دفاتر (ضغطة للفتح، ضغطة مطوّلة للحذف).
4. **إنشاء دفتر:** النسبة، والزوايا، والتجليد، ولون الورق ونقشه، ولون الغلاف، وغلاف جاهز أو صورة من الآيفون (دون إذن الوصول إلى المكتبة) مع سحب وتقريب لضبطها، واسم اختياري، ومعاينة ثلاثية الأبعاد حيّة. ثم ينفتح الغلاف إلى الصفحة الأولى.
5. **المحرر:** الصفحة تملأ الشاشة. كتابة بالكيبورد على السطور مباشرة (اتجاه كل فقرة تلقائي)، ورسم بالإصبع عبر PencilKit، وتنسيق خفيف (عريض/مائل/تسطير) من قائمة التحرير.
6. **الشريط العائم:** يومي، شهري، عادات، خواطر، فهرس، رسم. كل أداة تكتب قالبها داخل صفحات الدفتر نفسه.
7. **تقليب الصفحة:** اسحب طرف الصفحة. ينحني الورق تحت إصبعك، ويتبع السرعة والاتجاه، ويظهر ظهر الورقة وظلّه، ويستقر بنابض فيزيائي أو يعود إن أفلتّه مبكرًا. السحب بعد آخر صفحة يضيف صفحة جديدة بالورق نفسه.
8. **الحفظ:** زر «حفظ» العائم يكتب كل شيء في التخزين المحلي، ويعرض تأكيدًا مع زر «العودة إلى دفاتري». إعادة الفتح تعود إلى آخر صفحة. الخروج مع تغييرات غير محفوظة يعرض تنبيهًا واحدًا.

## البنية

| المجلد | المحتوى |
|---|---|
| `Waraq/App` | نقطة البداية، حالة التطبيق، الألوان والخطوط وأبعاد الصفحة، اللغتان |
| `Waraq/Model` | نماذج البيانات، التخزين في ملفات محلية، جلسة الدفتر المفتوح ومنطق Bullet Journal |
| `Waraq/Views` | اللغة، الترحيب، دفاتري، الإعدادات |
| `Waraq/Notebook` | رسم الغلاف، المعاينة ثلاثية الأبعاد، شاشة الإنشاء، قص الصورة، فتح الغلاف |
| `Waraq/Paper` | ملمس الورق ونقوشه |
| `Waraq/Editor` | القارئ (UIKit)، سطح الصفحة، الكتابة، الرسم، الشريط، الحفظ |
| `Waraq/Templates` | يومي، تقويم الشهر وخطته، العادات، الخواطر، الفهرس |
| `Waraq/Curl` | محرك تقليب الصفحة بـ Metal، الفيزياء، صوت الورق المولَّد آنيًا، الاهتزاز |

**التخزين:** `Application Support/Notebooks/<id>/` فيه `notebook.json` (الصفحات والقوالب) و`pages/*.rtf` (النص بتنسيقه) و`pages/*.drawing` (الرسم) و`cover.jpg`. الإعدادات (اللغة، الصوت، آخر صفحة) في UserDefaults فقط.

**تقليب الصفحة:** نموذج طيّ أسطواني. نقطة الطرف الممسوكة تتبع الإصبع بدقة، مقيّدة بحيث تبقى الورقة متصلة بالكعب، ونصف قطر الانحناء يكبر مع السرعة. عند الإفلات يحمل نابض مُخمَّد بسرعة الإصبع الورقة إلى الأمام أو يعيدها. الرسم بشبكة Metal (44×60) مع إضاءة وظهر للورقة وظل على الصفحة التحتية. الدفاتر العربية تُقلَّب من اليسار إلى اليمين، والإنجليزية بالعكس. مع خيار «تقليل الحركة» تصبح الانتقالات الآلية تلاشيًا.
